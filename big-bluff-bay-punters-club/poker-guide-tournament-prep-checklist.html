Poker Guide: Tournament Prep Checklist

Apply this guide with your weekly event plan for better consistency and stronger decision quality.

Why prep wins

Most avoidable mistakes happen before the first hand. A short prep routine increases EV immediately.

Pre-session checklist

  • Confirm your event slate from Poker Schedule.
  • Set bankroll cap and stop-loss.
  • Clear distractions and set note template.
  • Define one technical focus for tonight.

During-session checklist

  • Track table dynamics every orbit.
  • Pause before marginal all-ins.
  • Avoid adding events while tilted.

Post-session checklist

  1. Record 3 key hands.
  2. Write one improvement action.
  3. Update next-session plan.

Fast-start template

If unsure, play one core event only and execute cleanly. Consistency beats overload.
