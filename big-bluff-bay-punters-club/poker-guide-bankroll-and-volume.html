Poker Guide: Bankroll + Volume Framework

Most players don’t fail from lack of knowledge — they fail from inconsistent structure. This framework gives you a stable weekly system for event selection, bankroll discipline, and post-session review.

1) Build a weekly bankroll envelope

  • Set a fixed weekly bankroll before Monday.
  • Split into: core events, optional events, and buffer.
  • Never borrow from next week’s envelope to chase losses.

2) Plan volume, then protect quality

  • Pick your anchor events from Poker Schedule.
  • Add optional events only if energy/focus are strong.
  • Quality decisions beat raw hand count over time.

3) Review loop (non-negotiable)

  1. Log one good fold, one bad call, one key adjustment each session.
  2. Track whether mistakes are technical or emotional.
  3. Apply one change to the next session only (keep it simple).
