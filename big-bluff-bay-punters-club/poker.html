What the club is

Big Bluff Bay Poker Club is a social tournament-style poker group. We run structured nights with clear start times, agreed buy-ins, and respectful table culture.

Freeroll feature: when the Bosses Multi lands, that week’s Punters Club players receive a next-day Poker freeroll for the full amount.

  • Tournament format: No-limit hold’em with blind levels.
  • Community first: Friendly table, competitive mindset.
  • Consistent structure: Same rules each week.

Poker FAQ

Do I need to be in Punters Club to join poker nights?

You should register in Punters Club first so we can verify player details and week eligibility.

How do freerolls work?

When Bosses Multi lands, eligible players from that week are added to a next-day freeroll for the full amount.

What game format is used?

No-limit Hold’em tournament format with structured blind levels.

Can new players join mid-season?

Yes, subject to seat availability and host approval.

Where are tournament updates posted?

Updates are posted through club channels and site announcements.
